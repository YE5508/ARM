# 武汉大学 Robocon 2026 校内赛 A2 组

## 天空块夹取机构控制系统

这是武汉大学 Robocon 2026 校内赛 A2 组天空块机构的 STM32 控制代码。机构面向比赛中的“取块、搬运、放块”流程，通过两个关节电机完成机械臂姿态控制，并通过电磁阀驱动夹爪开合。

本目录只包含天空块机构相关的业务层代码，底层电机驱动、FDCAN、定时器和板级外设由工程中的 `Motor/`、`Communication/`、`BSP/` 和 `Application/` 模块提供。

## 项目亮点

- **双执行器协同控制**：Unitree GO-M8010-6 负责主摆臂运动，AK80（ZDrive 接口）负责另一关节调节，两者以统一姿态表协同到位。
- **动作抽象为工作姿态**：将复杂的电机目标值封装为抓取、放置、搬运、静默和取球五种模式，上层只需发送动作指令。
- **五次多项式轨迹**：GO 电机从实时反馈位置出发，使用 `Quintic_Traj()` 生成平滑位置轨迹，减少突变和机械冲击。
- **中断与控制解耦**：CAN 接收中断只登记待执行模式，真正的轨迹切换在 1 kHz 定时器控制周期中完成，避免在中断里直接执行较重的动作逻辑。
- **动作完成可查询**：GO 轨迹结束且 AK80 位置误差小于阈值后，统一置位 `FinishFlag`，便于主控编排后续流程。
- **故障与复位链路**：支持机构使能状态回传、报警帧转发和远程复位请求。

## 系统结构

```text
主控板
  │  FDCAN1 扩展帧
  ▼
天空块从板（STM32）
  ├─ Sky_Receive()   解析动作命令，登记 RequestedMode
  ├─ Sky_Func()      1 kHz 更新姿态轨迹与完成状态
  │    ├─ Unitree GO-M8010-6（UART7 / RS485）
  │    └─ AK80（ZDrive / CAN）
  └─ Jaw_Receive()/Jaw_Func()
       └─ 电磁阀通道 1，控制夹爪开合
```

在 `Application/src/IQRhandler.c` 中，`TIM2` 以 1 kHz 调用 `Sky_Func()` 和 `Jaw_Func()`；Unitree 电机通信同样在该时序下运行，ZDrive 的周期处理按 200 Hz 分频执行。FDCAN 接收回调直接调用 `Sky_Receive()` 与 `Jaw_Receive()`。

## 工作模式

姿态编号与 CAN 协议保持一致，修改枚举顺序时需要同步修改主控协议。

| 模式 | GO 目标位置（rad） | AK80 目标位置 | 用途 |
| --- | ---: | ---: | --- |
| `Sky_Grab_Mode` | `-1.84` | `260.0` | 取天空块 |
| `Sky_Put_Mode` | `-1.20` | `870.0` | 将天空块放至塔顶 |
| `Sky_Carry_Mode` | `-1.155` | `260.0` | 搬运姿态 / 机械臂复位 |
| `Sky_Silent_Mode` | `-0.615` | `98.8` | 上电后的安全静默姿态 |
| `Sky_Ball_Mode` | `-1.57` | `260.0` | 取球动作姿态 |

所有姿态默认使用 `GO_TIME = 3000 ms`。GO 的目标位置以电机反馈位置为当前轨迹起点，AK80 使用驱动接口定义的角度单位；表中数值属于现场装机和标定结果，换机械结构或零点后必须重新标定。

## CAN 控制协议

CAN 使用扩展帧，数据长度字段为 DLC。命令帧由 `Sky_Receive()` 和 `Jaw_Receive()` 校验后执行。

### 主控板 -> 天空块从板

| 功能 | CAN ID | DLC | 数据 |
| --- | ---: | ---: | --- |
| 机构使能 | `0x01010401` | 2 | `M`, `0/1` |
| 抓取姿态 | `0x01010402` | 2 | `G`, `S` |
| 放置姿态 | `0x01010403` | 2 | `P`, `S` |
| 搬运 / 复位姿态 | `0x01010404` | 2 | `A`, `R` |
| 夹爪开合 | `0x01010405` | 2 | `R`, `0/1` |
| 系统复位 | `0x010104FF` | 2 | `R`, `S` |

另有报警查询帧 `0x010104EE`，从板收到后回传报警响应。

### 天空块从板 -> 主控板

| 功能 | CAN ID | DLC | 数据 |
| --- | ---: | ---: | --- |
| 机构使能状态 | `0x04010101` | 2 | `M`, `0/1` |
| 复位响应 | `0x040101FF` | 2 | `R`, `S` |
| 电机 / 机构报警 | `0x040101EE` | 约定待扩展 | 由故障类型定义 |

## 控制流程

1. `Sky_Init()` 绑定 GO 和 AK80 电机对象，设置 GO 的 `Kp/Kd`，初始化轨迹控制器和夹爪状态。
2. 主控发送机构使能命令后，两个关节进入工作状态，并请求 `Sky_Silent_Mode`。
3. 主控发送动作命令，CAN 回调只更新 `RequestedMode` 和 `ModeChangePending`。
4. `Sky_Func()` 在定时器上下文中应用模式，启动 GO 五次多项式轨迹并更新 AK80 目标角度。
5. GO 轨迹运行结束、且 AK80 实际位置与目标位置误差小于 `0.005` 后，`Sky_IsFinished()` 返回完成。
6. 收到复位命令时置位 `ResetFlag`，随后执行 MCU 软件复位；使能关闭时立即停止 GO 轨迹并关闭电机输出。

## 关键参数

| 参数 | 当前值 | 说明 |
| --- | ---: | --- |
| `USE_UNITREE` | `1` | 启用 Unitree GO 电机 |
| `USE_ZMDR` | `1` | 启用 ZDrive / AK80 |
| `MOTOR_UNITREE_UART` | `7` | GO 使用 UART7 RS485 |
| `MOTOR_ZDRIVE_COUNT` | `1` | 当前机构使用 1 个 ZDrive 电机 |
| `GO_TIME` | `3000 ms` | 姿态切换默认时长 |
| `JOINTAK_FINISH_THRESHOLD` | `0.005` | AK80 到位判定阈值 |

电机开关和总线配置位于 `Config/motor_config.h`。Unitree GO 带绝对编码器，上电后不会自动将机械零位清零；首次使能前应根据机构机械零位执行底层 `SetZero` 标定。

## 调试与移植建议

- 先单独验证 UART7 RS485、ZDrive CAN 和电磁阀输出，再联调完整动作链路。
- 姿态参数应从安全低速开始调整，优先确认机械限位、零位方向和减速比。
- 调整 `GO_TIME` 可改变动作快慢；调整 `JOINTAK_FINISH_THRESHOLD` 可改变 AK80 的到位判定严格程度。
- 若更换电机或机构尺寸，应同时检查 `UnitreeMotor_Use_ID`、`ZdriveMotor_Use_ID`、减速比、姿态表和夹爪输出通道。
- 复位命令会触发 MCU 软件复位，不建议在机械仍受力或限位不明确时频繁使用。

## 作品集摘要

我负责天空块夹取机构的嵌入式控制实现，将两个异构关节执行器和电磁夹爪封装为可由主控通过 CAN 调度的动作模块。实现中重点处理了多电机同步、平滑轨迹、实时控制周期与通信中断解耦，并为动作完成、远程复位和故障回传预留了清晰接口。

这套代码体现的工程能力包括：STM32 HAL / C 语言开发、FDCAN 扩展帧协议设计、RS485 电机通信、周期控制任务组织、轨迹规划、执行器状态管理，以及面向比赛现场的参数化调试。
